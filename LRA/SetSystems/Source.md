# SetSystems Sources

This file records mathematical sources that inform the `LRA.SetSystems` subject.
The repository is organized by mathematical ownership rather than by textbook,
so source attribution does not determine module names or dependency boundaries.

## Primary Boolean-algebra source

### Steven Givant and Paul Halmos — *Introduction to Boolean Algebras*

Use this text as a principal source for the Boolean-algebraic viewpoint on
structured systems of sets, especially the relationship among Boolean rings,
Boolean algebras, fields/algebras of sets, ideals, homomorphisms, and related
representation results.

The source is particularly relevant to the `SetSystems` ↔
`AlgebraicStructures` relationship layer: `SetSystems` owns the set-theoretic
structures themselves, while generic Boolean rings and Boolean algebras remain
owned by `AlgebraicStructures`; classification and representation theorems
connect the two subjects.

Bibliographic note: Steven Givant and Paul Halmos, *Introduction to Boolean
Algebras*, Undergraduate Texts in Mathematics, Springer, 2009.
