# Associativity Proof Order

## Definitions

- [ ] Define associativity for a binary endo-operation.

## Direct Theorems

- [ ] Reassociate one triple from left-nested to right-nested.
- [ ] Reassociate one triple from right-nested to left-nested.
- [ ] Reassociate four elements from fully left-nested to fully right-nested.
- [ ] Reassociate four elements in the mixed forms needed by inverse proofs.

## Learning Checks

- [ ] Associativity does not imply commutativity.
- [ ] Associativity does not imply existence of an identity.
- [ ] Associativity does not imply existence of inverses.
- [ ] Associativity is exactly what makes parenthesis changes legal.

## Bridge Checks

- [ ] Additive associativity wrappers should point back to this generic law.
- [ ] Multiplicative associativity wrappers should point back to this generic
      law.
