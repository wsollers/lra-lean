# Closure Proof Order

## Definitions

- [ ] Define closure of a predicate/subcarrier under a unary operation.
- [ ] Define closure of a predicate/subcarrier under a binary operation.
- [ ] Define closure of an arbitrary unary operation into an intended carrier.
- [ ] Define closure of an arbitrary binary operation into an intended carrier.
- [ ] Record that an endo-operation is closed by type.

## Direct Theorems

- [ ] Apply unary predicate closure.
- [ ] Apply binary predicate closure.
- [ ] Apply arbitrary-operation closure into an intended carrier.
- [ ] Convert a closed ambient operation on a subtype/predicate into an
      endo-operation when the implementation strategy calls for it.

## Relationship Theorems

- [ ] Binary endo-operations have closure by construction.
- [ ] External binary operations are closed on the carrier output side by type.
- [ ] Pointwise operations inherit closure from the codomain operation.
- [ ] Closure is required before asking whether an element can be an identity
      for an operation on the intended carrier.
- [ ] Closure is required before associativity can be read as a law internal to
      the intended carrier.

## Learning Checks

- [ ] Closure is not associativity.
- [ ] Closure is not identity.
- [ ] Closure is not well-definedness under equivalence.
- [ ] Type-level closure is real, but it can be pedagogically invisible.
- [ ] Subset closure is the bridge from ambient operations to internal
      operations.

## Volume II Checks

- [ ] Concrete number systems prove their operations are total on the carrier.
- [ ] Quotient-style systems prove operations are well-defined under
      equivalence.
- [ ] Subcarrier-style systems prove the carrier is closed under inherited
      ambient operations.
- [ ] After closure/well-definedness, the system certifies the generic laws.
