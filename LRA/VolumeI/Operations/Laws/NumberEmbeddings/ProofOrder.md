# Number Embeddings And Mixed Operations Proof Order

## Definitions

- [ ] Define operation preservation by an embedding.
- [ ] Define distinguished-element preservation by an embedding.
- [ ] Define common-carrier interpretation for mixed operations.
- [ ] Define result-carrier ownership for mixed operations.

## Direct Theorems

- [ ] If an embedding preserves addition, embedded addition agrees with adding
      after embedding.
- [ ] If an embedding preserves multiplication, embedded multiplication agrees
      with multiplying after embedding.
- [ ] If both inputs embed into a common carrier, the mixed operation is an
      endo-operation in that common carrier.

## Relationship Theorems

- [ ] Mixed-carrier operation is not an endo-operation before choosing a
      result carrier.
- [ ] Closure for mixed operations is closure into the result carrier, not
      closure into each input carrier.
- [ ] Volume II number systems should certify embeddings before reusing
      generic laws across systems.

## Learning Checks

- [ ] `SystemA -> SystemB -> ResultSystem` is not the same shape as
      `Carrier -> Carrier -> Carrier`.
- [ ] Coercions are mathematical commitments, not invisible magic.
- [ ] The larger carrier must be specified and certified.
