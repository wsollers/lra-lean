## Direct Theorems

- [ ] Apply left absorption to any element.
- [ ] Apply right absorption to any element.
- [ ] Project left absorption from two-sided absorption.
- [ ] Project right absorption from two-sided absorption.
- [ ] Assemble two-sided absorption from left and right absorption.

## Relationship Theorems

- [ ] Left absorbing plus commutativity gives right absorbing.
- [ ] Right absorbing plus commutativity gives left absorbing.
- [ ] If an element is both a two-sided identity and a two-sided absorber, then
      the carrier collapses in the expected way.
- [ ] Absorbing elements explain common cancellation failures.

## Learning Checks

- [ ] Neutral element and absorbing element are different concepts.
- [ ] Zero for addition and zero for multiplication usually play different
      roles.
- [ ] Absorption does not imply identity.
- [ ] Identity does not imply absorption.
