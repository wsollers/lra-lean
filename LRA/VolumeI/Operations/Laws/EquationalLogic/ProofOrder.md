# Equational Logic Proof Order

## Definitions

- [ ] Reserve equality compatibility for unary operations.
- [ ] Reserve left argument equality compatibility for binary operations.
- [ ] Reserve right argument equality compatibility for binary operations.
- [ ] Reserve two-argument equality compatibility for binary operations.
- [ ] Reserve substitution-through-expression language.

## Direct Theorems

- [ ] Equal left inputs give equal outputs.
- [ ] Equal right inputs give equal outputs.
- [ ] Equal pairs of inputs give equal outputs.
- [ ] Equality compatibility composes through nested operation expressions.

## Relationship Theorems

- [ ] Addition property of equality is a notation-specific instance.
- [ ] Multiplication property of equality is a notation-specific instance.
- [ ] Substitution in algebraic expressions is repeated equality
      compatibility.

## Learning Checks

- [ ] Equality compatibility is not associativity.
- [ ] Equality compatibility is not commutativity.
- [ ] Replacing equals by equals changes expression parts, not operation
      order.
