# Identity Laws Proof Order

This checklist is intentionally concept-first. Complete it from top to bottom.

## Definitions

- [ ] Define left identity.
- [ ] Define right identity.
- [ ] Define two-sided identity.
- [ ] Record neutral element terminology.
- [ ] Record unit element terminology.

## Direct Theorems

- [ ] A left identity law applies to any element.
- [ ] A right identity law applies to any element.
- [ ] A two-sided identity supplies a left identity.
- [ ] A two-sided identity supplies a right identity.
- [ ] Left and right identity laws assemble into a two-sided identity law.

## Relationship Theorems

- [ ] A left identity and a right identity for the same operation coincide.
- [ ] Two two-sided identities for the same operation are equal.
- [ ] A two-sided identity is unique.

## Learning Checks

- [ ] State explicitly that identity uniqueness does not require associativity.
- [ ] State explicitly that left identity alone does not imply right identity.
- [ ] State explicitly that right identity alone does not imply left identity.
- [ ] State explicitly that associativity alone does not imply existence of an
      identity.

## Bridge Checks

- [ ] Additive zero as neutral is mapped to two-sided identity for addition.
- [ ] Multiplicative one as unit is mapped to two-sided identity for
      multiplication.
- [ ] Volume II concrete number systems certify the generic law before using
      generic identity theorems.
