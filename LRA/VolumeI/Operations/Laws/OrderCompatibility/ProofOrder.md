# Order Compatibility Proof Order

## Definitions

- [ ] Define left translation preserving a relation.
- [ ] Define right translation preserving a relation.
- [ ] Define coordinatewise operation preserving a relation.
- [ ] Define strict preservation by positive multiplication-like operation.
- [ ] Define non-strict preservation by nonnegative multiplication-like
      operation, if needed.
- [ ] Define order reversal by negative multiplication-like operation.

## Direct Theorems

- [ ] Apply left-translation preservation.
- [ ] Apply right-translation preservation.
- [ ] Apply coordinatewise preservation.

## Relationship Theorems

- [ ] Commutativity transfers left-order compatibility to right-order
      compatibility.
- [ ] Coordinatewise preservation follows from compatible one-sided
      translations under appropriate hypotheses.
- [ ] Ordered additive structures instantiate translation preservation.
- [ ] Ordered multiplicative structures instantiate positive multiplication
      preservation.
- [ ] Ordered ring-like structures instantiate negative multiplication order
      reversal.

## Learning Checks

- [ ] Preservation is not reflection.
- [ ] Strict preservation and non-strict preservation are different.
- [ ] Addition-like and multiplication-like order compatibility require
      different hypotheses.
- [ ] Positive multiplication is not the same as arbitrary multiplication.
- [ ] Negative multiplication is order reversing, not order preserving.
