# Cancellation Proof Order

## Definitions

- [ ] Define left cancellation.
- [ ] Define right cancellation.
- [ ] Define two-sided cancellation.

## Direct Theorems

- [ ] Apply left cancellation to an equality.
- [ ] Apply right cancellation to an equality.
- [ ] Project left cancellation from two-sided cancellation.
- [ ] Project right cancellation from two-sided cancellation.
- [ ] Assemble two-sided cancellation from left and right cancellation.

## Relationship Theorems

- [ ] Left inverse plus associativity plus identity gives left cancellation.
- [ ] Right inverse plus associativity plus identity gives right cancellation.
- [ ] Two-sided inverses give two-sided cancellation.
- [ ] In a commutative operation, left cancellation implies right cancellation.
- [ ] In a commutative operation, right cancellation implies left cancellation.

## Learning Checks

- [ ] Cancellation is not the same thing as identity.
- [ ] Cancellation is not the same thing as inverse.
- [ ] Associativity is where cancellation proofs usually turn.
- [ ] Operations with absorbing elements often fail cancellation.
