# Neutral And Unit Language

## Neutral Element

Use "neutral element" as pedagogical language for an identity element of a
binary operation.

For addition-like operations, `0 is neutral` should mean:

```text
0 is a two-sided identity for the addition operation
```

## Unit Element

Use "unit element" here as pedagogical language for the identity element of a
multiplication-like operation.

For multiplication-like operations, `1 is a unit` should mean:

```text
1 is a two-sided identity for the multiplication operation
```

## Warning

Some algebra texts use "unit" to mean an invertible element, not the
multiplicative identity. When this topic says "unit element", it means the
identity element unless a later inverse topic explicitly says otherwise.

## Implementation Target

The generic identity law remains operation-parametric. Notation-specific
phrases such as zero, one, addition, and multiplication belong in bridge files
or algebraic-structure wrappers.
