# Congruence Proof Order

## Definitions

- [x] Define unary operation congruence over an endorelation.
- [x] Define binary operation congruence over an endorelation.
- [x] Define relation requirements as equivalence plus congruence.

## Direct Theorems

- [x] Unary congruence applies to related inputs.
- [x] Binary congruence applies to related input pairs.
- [x] Relation-requirement projections expose equivalence and congruence.

## Relationship Theorems

- [x] Binary congruence gives left-side congruence under reflexivity.
- [x] Binary congruence gives right-side congruence under reflexivity.

## Learning Checks

- [ ] Operation congruence is not automatic for arbitrary relations.
- [ ] Operation congruence is not associativity or commutativity.
- [ ] Quotient operations require representative independence.
