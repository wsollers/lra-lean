## Spec (given by the user)

`(G, *)`: closure, associativity, identity (`e * x = x * e = x`), two-sided
inverses (`x * y = y * x = e`, `y := x⁻¹`). Consequences noted: uniqueness of
identity/inverses, cancellativity (both follow from the axioms, not separate
content — not built). Abelian if `*` is also commutative. Standard examples:
`(ℤ, +)`, `(ℚ\{0}, ×)`/`(ℝ\{0}, ×)`, `Sym(S)` under composition (non-abelian
for `|S|≥3`), `GL_n(ℝ)` under matrix multiplication (non-abelian for `n≥2`).

## A real bug — caught by `lake build` itself, in my own new code

The first draft of `Constructions/Set/ClosedSubset.lean`'s
`ClosedSubsetGroupLaws` required **`[GroupLaws A]` on the ambient type**.
This is wrong for the most natural real use case: `(ℝ\{0}, ×)`. `ℝ` itself is
only a `Monoid` under `×` (`0` has no inverse) — `GroupLaws ℝ` isn't just
unbuilt, it's **false** (there's no term of it, since `0⁻¹ * 0 = 0 ≠ 1`), so
`lake build` failed outright trying to synthesize it when building
`NonzeroRealsUnderMultiplication`.

Fixed by weakening the ambient hypothesis to `[MonoidLaws A]` and adding an
explicit per-subset `hInvCancel : ∀ a ∈ S, a⁻¹ * a = 1 ∧ a * a⁻¹ = 1`
hypothesis — exactly the fact `[GroupLaws A]` would have given for free, but
now supplied (and only needed) for elements of `S`, not the whole ambient.
This makes the builder usable for the textbook "unit group carved out of a
non-group ambient" pattern (units of a ring, invertible matrices within all
matrices, etc.), not just genuine subgroups-of-groups — which is arguably the
*more* common real-world shape for a concrete group example. Worth carrying
this lesson into `AdditiveGroup`'s own closed-subset builder.
