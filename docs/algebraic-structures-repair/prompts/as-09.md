# as-09 — MeetSemilattice

**STATUS: done, 2026-08-26.**

## Spec (given by the user)

Order-theoretic and algebraic definitions, confirmed equivalent to each other,
matching as-08's JoinSemilattice presentation exactly with `∧`/inf in place of
`∨`/sup:

- Order: `(P, ≤)` a poset where every pair `x, y` has a greatest lower bound
  `x ∧ y`.
- Algebra: `(S, ∧)`, non-empty, with `∧` idempotent, commutative, associative
  (equivalently, an idempotent commutative semigroup).
- Equivalence: order → algebra via `x ∧ y := inf{x, y}`; algebra → order via
  `x ≤ y ↔ x ∧ y = x`.
- Standard examples given: subsets under intersection (`(𝒫(X), ∩)`),
  divisibility on positive integers (`(ℕ_{>0}, ∣)`, meet = `gcd`), reals under
  min (`(ℝ, min)`).
