# as-14 — AdditiveGroup

**STATUS: done, 2026-08-26.**

## Spec (given by the user)

`(G, +, 0, -)`: closure, associativity, identity (`x+0=0+x=x`), two-sided
inverse (`x+(-x)=(-x)+x=0`). Noted: additive-notation groups are
conventionally abelian in practice (that's `AbelianGroup`'s own content, not
built here), cancellativity follows from the axioms, subtraction is defined
globally as `x-y := x+(-y)`. Standard examples: `(ℤ,+,0,-)`, `(ℝⁿ,+,0,-)`,
`(M_{m×n}(ℝ),+,0,-)`, `(ℤ/nℤ,+,0,-)`.

## Audit

`AdditiveGroupLaws R := AdditiveSemigroupLaws R, AdditiveIdentityLaws R,
AdditiveInverseLaws R` (`[Nonempty R]` per D7) — exact dual of `Group`'s
`GroupLaws`. `AdditiveInverseLaws`'s two fields (`NegAddCancel : -a+a=0`,
`AddNegCancel : a+-a=0`) match the user's axiom 4 exactly. No bug found.
Also confirmed `SubtractionCompatibilityLaw` (`a-b=a+-b`) correctly matches
the user's own "subtraction as inverse operation" convention — legitimate
bonus atomic content, not core-axiom content, correctly placed.
