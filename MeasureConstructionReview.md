# Basic measure consequences and exact hypotheses

## Finite additivity

For measurable disjoint `A,B`, derive

```text
mu (A union B) = mu A + mu B.
```

This should be an immediate specialization of countable additivity.

## Monotonicity

For measurable `A subset B`, derive

```text
mu A <= mu B.
```

The usual proof decomposes `B = A union (B \ A)` disjointly and uses nonnegativity of `ENNReal`.

## Difference formula

For measurable `A subset B` and `mu A < infinity` (or another orientation with the corresponding finite term), derive the appropriate subtraction identity.

The finiteness hypothesis must be explicit because extended-real subtraction is delicate at infinity.

## Countable subadditivity

For measurable `A_n`, derive

```text
mu (union_n A_n) <= sum_n mu (A_n).
```

The standard disjointification proof is worth exposing pedagogically.

## Continuity from below

For an increasing measurable sequence `A_n`,

```text
mu (union_n A_n) = sup_n mu (A_n).
```

No finite-measure assumption is needed.

## Continuity from above

For a decreasing measurable sequence `A_n`,

```text
mu (intersection_n A_n) = inf_n mu (A_n)
```

requires a standard finite-measure hypothesis, e.g. `mu (A_0) < infinity`.

That hypothesis should not be omitted.

# Measure examples

## Dirac measure

This is the best first nontrivial example:

```text
delta_x(A) = 1 if x in A, else 0.
```

It works on any measurable space where the definition is interpreted on measurable sets and makes countable additivity concrete.

## Counting measure

Counting measure is the natural second example:

```text
mu(A) = cardinality(A)
```

with infinity allowed for infinite sets.

These two examples should precede Lebesgue measure because they require no extension theorem and isolate the measure axioms cleanly.
